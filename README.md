## 📌 Project Overview

This project explores a curated dataset of Netflix titles to examine movie trends from the **1990s**—a pivotal decade in modern cinema. Through data cleaning, filtering, and visual exploration, the analysis answers questions such as:

- What were the most common movie runtimes during the 1990s?
- How frequently did specific genres (e.g., Action, Drama, Comedy) appear?
- Were short films (< 90 minutes) common among specific genres during this era?
